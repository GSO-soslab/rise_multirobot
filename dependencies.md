## ROS Dependencies
sudo apt-get install ros-jazzy-geographic-msgs ros-jazzy-robot-localization ros-jazzy-bondcpp ros-jazzy-tf-transformations

## Linux Dependencies
sudo apt-get install libglm-dev libsdl-dev libfreetype6-dev libgsl-dev

## Nvidia for stonefish
sudo prime-select nvidia
sudo nvidia-smi -pm 1/0 to turn on/off persistance mode.
